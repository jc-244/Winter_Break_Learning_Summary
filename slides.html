Tab 5 Report

Reading: Key Papers — ToT and ReAct

Summary: ToT explores thought space; ReAct grounds reasoning via actions.

ToT — search over candidate reasoning paths.

Value comes from tree-like branching + scoring, not longer CoT.

ReAct — closed-loop reasoning with tool interactions.

The loop (Action → Observation) prevents “free-floating” reasoning.

Key takeaway: The bottleneck is evaluation + replay under partial observability— without that, “search” is just noise.

Tab 5 Report

Reading: Key Papers — EXACT

Summary: See the flowchart — ExACT turns budgeted exploration on the real web into an engineering-friendly system: traceable, reusable, and modular.

Agent paradigm: ReAct-style loop (thought → action/tool → observation), with the interaction process standardized into executable steps + logs.

Reasoning / decision-making: Tree-based, search-based control for when to branch, evaluate, backtrack, and replay—rather than a single linear chain like CoT.

Key takeaway: The “stable large-system framework” design: under the repo's scaffold, components (agent/policy / evaluator / env / tools, etc.) can be swapped reliably as long as interfaces stay stable—algorithms can change, the system still runs.
